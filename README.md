# ⚡ Projeto Eletricista - Projeto Integrador

## 📖 Sobre o Projeto

Aplicação web voltada para a solicitação e prestação de serviços elétricos. Este sistema está sendo construído como parte dos requisitos do Projeto Integrador da faculdade.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação da base da aplicação.
- **CSS3:** Estilização e layout responsivo.
- **JavaScript:** Lógica de negócios e interatividade.
